Install and update

Prepare Flatpak

Set up Flatpak on Ubuntu once, so you can install Typecase. On Fedora and Linux Mint, it's already there.

Show the commands

Install Flatpak

sudo apt install flatpak

Let the Software app install Flatpaks

sudo apt install gnome-software-plugin-flatpak

Add Flathub

sudo flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

Then restart your computer once.

Read the narration

Typecase comes as a Flatpak, a kind of app that runs on almost every Linux. On Ubuntu, Flatpak needs a short setup, just once. On Fedora or Linux Mint it's already there, so you can skip this video. Everything happens in the Terminal. Open it from the search, or press Control, Alt and T. Don't worry: three commands, and you're done. First, install Flatpak itself. Ubuntu asks for your password: type it, the letters stay invisible, and press Enter. When Ubuntu asks whether to continue, press Enter again. Second, teach the Software app about Flatpak. That's what lets you install Typecase with a double click. Third, add Flathub. Typecase gets the parts it needs from there. That's it. Restart your computer once, so that new apps show up. You'll find the commands below this video, ready to copy.

Install Typecase

Download Typecase, install it with a double click, and add dictionaries for more languages.

Show the commands

Install the downloaded file from your Downloads folder (use the name of the file you downloaded)

sudo flatpak install ~/Downloads/Typecase-1.3.0-x86_64.flatpak

Add dictionaries for more languages, here German and English (use your language codes)

sudo flatpak config --set languages "de;en"

Download them

sudo flatpak update
Read the narration

Now let's install Typecase. If you're on Ubuntu, set up Flatpak first, as shown in the previous video. Open kleinod.studio/typecase in your browser and click Get Typecase. Pick the download for your computer. Most PCs need x86_64. ARM computers, like this one, need the second button. Open your Downloads folder and double-click the file. The Software app opens. Click Install and type your password. Software may warn that Typecase can read and write your files: it needs that to open the folder with your texts. Done. Typecase is now among your apps. Typecase checks your spelling. Dictionaries for your system's language usually come along. For more languages, add them in the Terminal, here German and English, and update. Prefer the Terminal for everything? You'll find all commands below this video.

Update Typecase

Check your version, download the new one, and install it over the old one in the Terminal.

Show the commands

Install the new file over the old one (use the name of the file you downloaded)

sudo flatpak install ~/Downloads/Typecase-1.3.0-x86_64.flatpak

Keep the GNOME runtime and the dictionaries up to date

sudo flatpak update
Read the narration

Typecase never goes online, so it doesn't look for updates by itself. Now and then, compare your version with the newest one. Your version is in the menu, under About Typecase. This one has 1.2.1. The newest version is on kleinod.studio/typecase, right below the buttons. Here it's 1.3.0. Download it, just like the first time: click Get Typecase, then the button for your computer. The Software app can't update from a downloaded file, so open the Terminal. Type sudo flatpak install and the start of the file name, then press Tab: the Terminal completes it. Press Enter, type your password, and confirm with Enter once more. Your texts and settings stay as they are. Open Typecase again and look at About Typecase: now it has 1.3.0. Tip: run sudo flatpak update now and then, to keep the parts Typecase builds on up to date. You'll find the commands below this video.

Write

First steps

Open Typecase for the first time, choose a folder for your library, and write your first sheet.

Read the narration

The first time you open Typecase, it asks for your library: the folder where your texts live. Pick a folder, or create a new one, like this one in Documents. Writing on more than one computer? Choose a folder that Nextcloud, Syncthing or another sync service keeps up to date. Now this folder is your library. Its subfolders become groups, its Markdown files become sheets. Click the plus button for a new sheet. Start writing. Your first heading becomes the name of the sheet. There's no Save button: Typecase saves as you type, into a plain Markdown file that any text editor can open. Next, learn how to format your text, with or without Markdown.

Markdown and the formatting bar

Why Typecase writes in Markdown, the few characters you need, and how to format without them.

Read the narration

Typecase writes in Markdown: plain text with a few characters for formatting. Why? Your texts stay ordinary text files. Any app on any computer can open them, today and in twenty years. And you write without fiddling with layout: the look comes later, when you export to PDF or Word. You don't have to learn the characters first. Here are the few you need. A hash sign starts a heading, two of them a smaller one. Two asterisks around a word make it bold, one makes it italic. The characters stay, but fade into the background. A dash starts a list. Press Enter, and the next item begins by itself. Rather not type the characters? Select a word and use the bar at the bottom. It also turns a line into a heading. Or use the keyboard: Ctrl+B for bold, Ctrl+I for italic, Ctrl+1 to 3 for headings. That's all you need. Everything else is just writing.

Focus mode

Hide everything but your text, with typewriter scrolling, dimmed surroundings and settings of its own.

Read the narration

Sometimes you want nothing on screen but your text. That's what focus mode is for. Press Ctrl+Shift+Enter, or choose Focus Mode from the menu. The sidebar and toolbars step aside. As you type, the line you're writing stays in the middle of the screen, like on a typewriter. Your eyes don't have to wander. Everything except the paragraph you're working on fades into the background. The formatting bar stays at hand. Move the pointer to the top edge, and the header bar comes back. In the preferences, focus mode can have its own font, size and theme, like a dark one just for writing. You can also switch off typewriter scrolling and dimming there. Press Escape to leave focus mode. Everything is back where it was. Just you and your text.

Organize

Icons and colors

Give groups and sheets an icon and a color, so they stand out in your library at a glance.

Read the narration

This is Typecase, a calm writing app for Linux. Your library is a folder of plain Markdown files, and at first, every group and sheet looks the same. To make a group stand out, right-click it and choose Icon and Color. Pick one of the nine accent colors from GNOME, then one of twenty-eight icons. Apply, and the group shows them right away. Give the other groups and sheets their own look, too. Characters, places, ideas and open questions now stand out at a glance. The colors follow the light and dark style. And nothing is hidden away: a sheet keeps its icon and color in its front matter, a group in its own folder, so they travel along when you move, copy or sync them.
