Writing, without distractions

A library of plain files

Any folder becomes your library; subfolders are groups. No database, no proprietary format. Sync it with Nextcloud or Syncthing if you like.

Markdown, styled as you type

Headings, emphasis, lists and code look the way they will. A floating formatting bar helps if you'd rather not learn the syntax.

Focus mode

Full screen with only your text. Typewriter scrolling keeps the current line centered, and the rest of the text fades back.

Goals and keywords

Set a word goal per sheet and watch the progress rings fill. Tag sheets with keywords and filter your library by them.

Your text is safe

Every change is saved automatically and atomically. If another program changes a file, Typecase never overwrites what you typed.

Private

No account, no telemetry, no network access. The Flatpak doesn't even have network permission.

Export with templates

Typecase exports to PDF, Word (DOCX) and HTML through Pandoc. How the result looks is decided by a template: a single .typecase-template file you import under Preferences → Templates. One template covers all three formats.

Build your own templates

The guide explains the format: description, HTML template, CSS and Word styles.

Editor themes

Choose the colors you write in: Standard, Paper, Solarized, Calm or High Contrast, each in a light and a dark variant that follows your system. Focus mode can have a theme of its own, and the whole window takes on the theme's colors.

Build your own themes

Themes are GtkSourceView style schemes, the format of GNOME Text Editor. Save a built-in theme as a file, change the colors and import it under Preferences → Writing → Themes.

Read the theme guide

Or use an existing scheme

Many color schemes made for gedit and GNOME Text Editor work in Typecase too, such as Catppuccin, Dracula, Nord or Gruvbox. Import the light and the dark file, and Typecase pairs them.

How to use them

Install

Typecase will come to Flathub with version 1.0; until then, install the Flatpak bundle.

First time with Flatpak?

Flatpak is a format for apps that runs on almost every Linux distribution. Fedora and Linux Mint come with it already set up, so you can skip this step. On Ubuntu, open a terminal and set it up once:

sudo apt install flatpak
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

The first command installs Flatpak, the second adds Flathub, where the GNOME runtime that Typecase needs comes from. Log out and back in afterwards, so that Flatpak apps appear in your app launcher. For other distributions, see flatpak.org/setup.

Install Typecase

Download for x86_64 Download for ARM (aarch64)

Most PCs need the x86_64 version. Then open a terminal in your downloads folder:

flatpak install --user Typecase-1.0.0-x86_64.flatpak

The GNOME runtime is fetched from Flathub automatically, and Typecase appears in your app launcher. Bundles don't update by themselves; install the next release the same way. Your library and settings stay.

Spell checking dictionaries

The dictionaries come from the GNOME runtime's language packs, which Flatpak installs only for the languages it is set up for. If Typecase says that a dictionary is missing, add the language (here German and English) and update:

flatpak config --user --set languages "de;en"
flatpak update --user

Build from source

git clone --branch v1.0.0 https://github.com/kleinod-studio/Typecase.git
cd Typecase
flatpak-builder --user --install --force-clean build-dir studio.kleinod.Typecase.yml

You need flatpak-builder and the GNOME runtime (flatpak install flathub org.gnome.Platform//51 org.gnome.Sdk//51).
